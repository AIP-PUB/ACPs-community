# Node SDK 与 Python SDK 的对应约定

本包是 `acps-sdk`（Python，v2.2.0）的 TypeScript 移植。目标是**线上格式与行为完全一致**，
API 形状在不违背 Node 习惯的前提下与 Python 版一一对应，便于两边对照维护。

## 1. 文件与命名

| Python                                  | Node                                                                                                                                                                                                          |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `acps_sdk/<pkg>/<module>.py`            | `src/<pkg>/<module 的 camelCase>.ts`；`aip_` 前缀去掉，例如 `aip_rpc_server.py` → `src/aip/rpcServer.ts`，`_message_tap.py` → `src/amp/messageTap.ts`，`alive_sync/engine.py` → `src/amp/aliveSync/engine.ts` |
| `<pkg>/__init__.py` 的导出              | `src/<pkg>/index.ts`，导出同一批名字（按下面规则改名）                                                                                                                                                        |
| 类名 `PascalCase`                       | 不变                                                                                                                                                                                                          |
| 函数 / 方法 `snake_case`                | `camelCase`（`format_traceparent` → `formatTraceparent`）                                                                                                                                                     |
| 模块常量 `UPPER_SNAKE`                  | 不变                                                                                                                                                                                                          |
| 关键字参数 `def f(a, *, trace_id=None)` | 末尾选项对象 `f(a, { traceId })`                                                                                                                                                                              |
| 返回元组 `(ok, err)`                    | 返回只读元组 `readonly [boolean, string \| null]`                                                                                                                                                             |
| `None`                                  | 返回值用 `null`；可选入参与可选字段用 `undefined`                                                                                                                                                             |
| `ValueError` / `TypeError`              | `Error` / `TypeError`；SDK 自定义异常保持同名 `class X extends Error`，并设置 `name`                                                                                                                          |
| `async def`                             | 返回 `Promise`                                                                                                                                                                                                |
| 同步 IO（如 `emit_sync`）               | 同步实现（`fs.appendFileSync` 等）                                                                                                                                                                            |

## 2. 模型（pydantic → zod 4）

- 每个 pydantic 模型导出 `XxxSchema`（zod）和 `type Xxx = z.output<typeof XxxSchema>`；需要时再导出 `XxxInput = z.input<...>`。
- **字段名用线上 JSON 名**：带 `Field(alias="camelCase")` 的字段，TS 字段就是 alias；没有 alias 的字段保持 Python 原名。
- `Optional[T] = None` 一律用 `optional(schema)`（`src/internal/schema.ts`）：接受 `null` 或缺省，解析为 `undefined`，键在类型上是可选的。
- 有默认值的字段用 `.default(...)`；字面量判别字段如 `type: Literal["text"] = "text"` 用 `z.literal("text").default("text")`。
- `Dict[str, Any]` 用 `AnyDict`；其内部的 `null` **保留**（pydantic 的 `exclude_none` 不会深入普通 dict）。
- pydantic 默认 `extra="ignore"` ↔ zod 默认对象（丢弃未知键）；`extra="allow"` ↔ `z.looseObject`；`extra="forbid"` ↔ `z.strictObject`。
- `field_validator` / `model_validator` 用 `.refine` / `.superRefine` / `.transform` 实现，错误信息尽量与 Python 原文一致（测试会比对）。
- 枚举：`class X(str, Enum)` → `export const X = { A: "a" } as const` + 同名类型 + `XSchema = z.enum(...)`。
- 序列化：`model_dump(exclude_none=True)` 对应「解析后的对象直接 `JSON.stringify`」。不要手写会删掉 dict 内部 null 的通用清理函数。
- 例外：AMP 的 NDJSON 日志行要与 Python `json.dumps` 逐字节一致（`", "` / `": "` 分隔符、float 写法），由 `src/internal/pyCompat.ts` 的 `pythonJsonDumps` 生成。
- 校验失败时如需把错误转成字符串，用 `formatZodError`。
- pydantic 模型上的方法 / classmethod 放在与类型同名的伴生常量对象上，例如 `DiscoveryRequest.fromDict(...)`、`AgentCapabilitySpec.fromFile(path)`。
- 根级 `model_validator` 用 `.superRefine(fn, { when: (p) => p.issues.length === 0 })`：pydantic 在字段校验失败时不会再跑模型校验器，zod 默认会跑。
- 有非 None 默认值、同时又接受显式 null 的字段：`.nullable().default(x).transform(v => v ?? undefined)`（缺省得默认值，显式 null 得 undefined 并在序列化时省略）。
- pydantic 宽松模式的类型转换（如 `"5"` → 5、`1` → True）不复现：Node 版按声明类型严格校验。

## 3. 时间、ID、日志

- 时间戳统一用 `utcNowIso()` / `toPythonIsoformat()`（`src/internal/time.ts`），格式同 Python `datetime.now(timezone.utc).isoformat()`。
- UUID 用 `crypto.randomUUID()`。
- 日志用 `getLogger(name)`（`src/internal/logger.ts`），默认静默，对应 Python 的 `NullHandler`。

## 4. HTTP / TLS

- 服务端不绑定框架：每个 Python `add_aip_xxx_router(app, ...)` 对应
  1. 一个与框架无关的核心处理函数（输入：解析后的 body + 对端身份；输出：响应对象），
  2. 一个 `createXxxRequestListener(...)`，返回 `(req, res) => Promise<void>`，可直接用于 `https.createServer` 或 Express 路由（通知端点的监听函数自己按路径分发，返回 `Promise<boolean>`，表示是否已处理该请求）。
- 对端身份读取 `req.socket.getPeerCertificate()`（见 `src/aip/peerCert.ts` 的 `getRequestPeerAic`）。**mTLS 必须在 Node 进程内终止**，与 Python 版要求一致。
- 客户端用 `node:https`（不用全局 fetch），这样才能从响应 socket 取到服务端证书做身份绑定；TLS 选项对应 Python 的 `ssl_context`：`{ cert, key, ca, servername?, rejectUnauthorized? }`。
- 测试用的 `transport` 注入：Python 用 `httpx.MockTransport`，Node 版客户端接受可选的 `transport` 函数，签名见 `src/internal/http.ts`。

## 5. 测试

- vitest。单元测试放 `test/<pkg>/*.test.ts`，需要真实 TLS / 网络的放 `test/integration/`。
- 尽量逐条移植 Python 的 `tests/` 用例（同名 describe/it，便于对照）。
- **跨语言对照样例**：用 Python 版 SDK 生成 JSON，Node 测试读取并比对。
  - 每个包一个生成脚本：`scripts/fixtures/gen_<pkg>.py`，输出到 `test/fixtures/python/<pkg>/*.json`。
  - 统一入口：`npm run fixtures:python`（在 `../../acps-sdk` 的 uv 环境里依次运行所有脚本）。
  - 生成脚本必须确定性（固定时间、ID、随机种子），生成结果提交进仓库。
- 测试证书：用 devDependency `@peculiar/x509` 在测试里现场生成（CA + 带 `CN=<AIC>`、`URI:acps://<AIC>` 的叶子证书），不要把私钥提交进仓库。

## 6. 与 Python 版有意不同的地方

| 方面                                            | Python                                                                                                           | Node                                                                                                                                                                                                                                                                                                        | 原因                                                                               |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| JSON-RPC 响应里的空字段                         | FastAPI `response_model` 会输出 `"error": null`、`"mentions": null` 等                                           | 省略值为空的字段；但 RPC 响应的 `id` 始终输出，无法确定请求 id 时为 `null`（JSON-RPC 2.0 与 AIP §5.1 要求）                                                                                                                                                                                                 | JSON-RPC 2.0 要求 `result` 与 `error` 互斥；双方解析器都把缺省与 null 视为同一含义 |
| 读取对端证书                                    | 自定义 uvicorn `H11Protocol` + Starlette 中间件写入 `request.state`                                              | 直接读 `req.socket.getPeerCertificate()`，按 socket 缓存；`setRequestPeerIdentity` 对应预先写入 `request.state.peer_aic`                                                                                                                                                                                    | Node 的请求对象直接暴露 TLS socket                                                 |
| 路由注册                                        | `add_aip_*_router(app, ...)` 绑定 FastAPI                                                                        | `createAip*RequestListener(...)` 返回 `(req, res)` 监听函数，路径匹配交给调用方                                                                                                                                                                                                                             | 不绑定任何 Web 框架                                                                |
| 测试替身                                        | `httpx.MockTransport`                                                                                            | 可注入的 `transport` / `streamTransport` 函数                                                                                                                                                                                                                                                               | 同上                                                                               |
| `@dataclass` 类型                               | 类实例                                                                                                           | 普通对象 + 接口（camelCase 字段）；例外：`AICInfo` 带计算属性（`isOntology`、`body` 等），保留为冻结的类                                                                                                                                                                                                    | TS 习惯                                                                            |
| 整数与浮点                                      | `float(12)` 序列化为 `12.0`                                                                                      | AIP / ACS / ADP 的 JSON 中写作 `12`；AMP 日志行与 Python 逐字节一致：声明为 float 的字段写 `12.0`，自由结构字段里小于 1e21 的整数值写成整数（Python 的 `2.0` 在这类字段里会写成 `2`）                                                                                                                       | JS 只有一种数字类型；接收方按数值解析，不受影响                                    |
| 客户端 `close()`                                | 关闭 httpx 连接池                                                                                                | 空操作（每个请求独立连接，确保读到的是本次连接的证书）                                                                                                                                                                                                                                                      | 身份绑定需要逐连接取证书                                                           |
| Access 日志 `request.bodySizeBytes`             | 用 `json.dumps(payload)` 默认格式（带空格、ASCII 转义）计算，与实际发送的请求体不同                              | 用实际发送的请求体字节数                                                                                                                                                                                                                                                                                    | Python 的数值不反映真实请求大小                                                    |
| SSE 行切分                                      | httpx `aiter_lines` 按 `str.splitlines` 切分，事件里含 U+2028 / U+2029 / U+0085 时会被丢弃                       | 按 SSE 规范只在 `\r` / `\n` 处切分，这类事件正常送达                                                                                                                                                                                                                                                        | Python 侧的问题，建议上游修复                                                      |
| RabbitMQ 断线重连                               | aio-pika `RobustConnection` 自动恢复通道、队列、绑定与消费者；任何恢复失败都拆掉整条连接，每 5 秒重试            | amqplib 只重连连接，本包在 `groupAmqp.ts` 里恢复通道、交换机、队列、绑定与消费者；某个通道恢复失败（如交换机暂时不存在）时只重试该通道（默认每 5 秒），连接与收件箱保持可用；恢复期间发布立即失败（调用方重试），声明类操作等待恢复，清理类操作快速失败；`isJoined` 与 `groupChannelError` 反映群组通道状态 | 避免一个通道失败拖垮收件箱等其他通道，同时保证能自动恢复                           |
| 日期时间精度                                    | `datetime` 微秒                                                                                                  | `Date` 毫秒                                                                                                                                                                                                                                                                                                 | JS 限制；邀请过期等计算只用到秒级                                                  |
| 未通过校验的对端证书                            | `ssl.getpeercert()` 对未校验证书返回空，不会产生身份                                                             | `getPeerCertificate()` 即使 `rejectUnauthorized: false` 也会返回证书，因此显式要求 `socket.authorized === true`，否则按认证失败处理（服务端 -32008，客户端视为没有服务端 AIC）                                                                                                                              | 防止自签证书冒充任意 AIC                                                           |
| 流式订阅在客户端断开后释放                      | Starlette 在断开时取消 SSE 生成器                                                                                | 监听函数在读取请求体之前就挂上断开监听（连接在前置中间件期间断开也能释放），并在写入已关闭的响应时立即结束；自行编写 HTTP 层时通过 `handleStreamRequest(..., { signal })` 传入                                                                                                                              | 行为等价，实现方式不同                                                             |
| 监听函数配置校验                                | 每个请求时检查 `local_aic`，缺失则请求返回 500                                                                   | 创建 `createAip*RequestListener` 时即校验                                                                                                                                                                                                                                                                   | 尽早暴露配置错误                                                                   |
| 通知分发器 `close()`                            | 关闭 httpx 客户端，进行中的重试仍会继续                                                                          | 中止进行中的回调请求与重试等待                                                                                                                                                                                                                                                                              | 避免关闭后仍有后台重试                                                             |
| 根入口导出                                      | 顶层包只有 `__version__`                                                                                         | 根入口只导出 `VERSION`、`setLoggerFactory` 与少量公共类型，各模块从子路径引入                                                                                                                                                                                                                               | 与 Python 一致；也避免打包后的命名空间类型声明出错                                 |
| 群组 ACL 网络错误                               | httpx 网络异常直接抛出                                                                                           | 包装为 `GroupAclError`（保留 `cause`）                                                                                                                                                                                                                                                                      | 调用方只需处理一种错误                                                             |
| 收件箱邀请的收尾                                | 超时监视与 `_handle_invitation_error` 在 ACL 清理出错时可能不结算邀请，`invite_partner` 永久挂起且残留待处理记录 | 无论清理是否成功都在 `finally` 中结算邀请并只删除自己的待处理记录；回滚失败不会覆盖原始错误                                                                                                                                                                                                                 | 修复 Python 侧的挂起问题，建议上游同步                                             |
| 邀请 token 日志                                 | token 不匹配时完整写入日志                                                                                       | 日志中脱敏为长度与摘要                                                                                                                                                                                                                                                                                      | 不在日志中暴露凭据                                                                 |
| 通道恢复失败的通知                              | 无                                                                                                               | `createAmqplibConnector(undefined, { onChannelRestoreFailed })` 与 `AmqpChannel.lastRestoreError`                                                                                                                                                                                                           | 让应用感知某个通道已不可用                                                         |
| 按字段名（snake_case）传入                      | `populate_by_name=True` 时同时接受别名与字段名，例如 `forward_chain`                                             | 只认线上的别名（camelCase），snake_case 键会被当作未知键忽略，对应的可选字段因此丢失                                                                                                                                                                                                                        | 只支持一种线上格式；从 Python 侧拿到的 dict 先按别名序列化再传入                   |
| 自由结构 dict 的键                              | 保持插入顺序；`__proto__` 作为普通键保留并参与校验                                                               | JS 对象会把整数形式的键（如 `"2"`）排到前面；`__proto__` 键在解析时被丢弃                                                                                                                                                                                                                                   | JS 对象语义；防止原型污染                                                          |
| 整数范围                                        | 任意精度整数                                                                                                     | 声明为整数的字段只接受安全整数（≤ 2^53−1）；`base36Encode` / `base36Decode` 超出范围抛 `RangeError`                                                                                                                                                                                                         | 超出后 JS 数字会丢精度                                                             |
| 超深嵌套的发现过滤条件                          | pydantic 返回 ValidationError                                                                                    | `DiscoveryRequest.fromDict` / `fromJson` 转换为 ZodError；直接调用 `Schema.parse` 时可能抛 RangeError（栈溢出）                                                                                                                                                                                             | zod 递归校验受调用栈限制                                                           |
| ESM 与 CJS 混用                                 | —                                                                                                                | 同一进程里既 `import` 又 `require` 本包会加载两份模块：日志工厂、`TaskManager` 等模块级状态各自独立，`instanceof` 跨两份失效                                                                                                                                                                                | 双包模式的固有问题；请在同一应用里只用一种方式引入                                 |
| 响应与 SSE 大小上限                             | 无上限                                                                                                           | 客户端传输层默认最多读取 64 MiB 响应体（`createNodeTransport(tls, { maxResponseBytes })`）；流式客户端单个事件 / 单行默认最多 16 Mi 字符（`maxEventChars`），超出即中止                                                                                                                                     | 防止异常对端耗尽内存                                                               |
| 流式客户端的续传序号                            | `start_stream` 不重置 `last_event_seq`，复用客户端时新任务可能沿用上一个任务的序号                               | `startStream` 时重置为 null                                                                                                                                                                                                                                                                                 | 修复 Python 侧问题                                                                 |
| re-stream 的 `lastEventSeq` 不是整数            | 比较时抛 TypeError，返回 500                                                                                     | 返回 400（-32602）                                                                                                                                                                                                                                                                                          | 明确的参数错误                                                                     |
| AMP float 字段的 NaN / Infinity                 | pydantic 接受，日志写 `NaN` / `Infinity`                                                                         | 同样接受并按 Python 写法输出；自由结构字段里的非有限数写 `null`（与 pydantic JSON 模式一致）                                                                                                                                                                                                                | 对齐 Python                                                                        |
| AMP 异步写入                                    | 每行一次 `f.write`                                                                                               | 同一文件的写入按调用顺序排队，每行一次同步 append（大行写入期间会阻塞事件循环）                                                                                                                                                                                                                             | 保证行不会被拆开或交错                                                             |
| AMP 周期任务                                    | 取消任务时抛 `CancelledError`                                                                                    | `runPeriodic` 在 `stop()` 或 AbortSignal 中止后正常返回；运行期间会保持进程存活                                                                                                                                                                                                                             | Node 习惯                                                                          |
| AMP 发射参数                                    | `emit(body, **kwargs)`                                                                                           | 只接受 trace 与 severity 选项；`signer`、`resource` 是构造参数                                                                                                                                                                                                                                              | 接口更明确                                                                         |
| AMP 解析辅助                                    | `int(x, 16)` / `str.isdigit` / `fromisoformat` 较宽松                                                            | `parseTraceparent` 只认严格十六进制；`seqFromStr` / `shardIndexFromId` 只认 ASCII 数字且限安全整数；`seekTimestampMs` 支持 `fromisoformat` 的常用子集（不含 ISO 周日期）                                                                                                                                    | 更严格，不影响合法输入                                                             |
| alive 快照解析错误                              | 非 UTF-8 或非对象行抛 `UnicodeDecodeError` / `AttributeError`                                                    | 统一抛 `SnapshotProtocolError`                                                                                                                                                                                                                                                                              | 让调用方能按协议错误触发重新同步                                                   |
| `DeltaDecision` 的值                            | `auto()` 整数                                                                                                    | 成员名字符串（如 `"APPLY_UPSERT"`）                                                                                                                                                                                                                                                                         | 便于日志与调试                                                                     |
| 日志 id                                         | `uuid4()`（Python 3.14 起为 v7）                                                                                 | UUID v4                                                                                                                                                                                                                                                                                                     | 与 Python ≤ 3.13 一致                                                              |
| 含孤立代理项的字符串                            | 写入失败，只记警告                                                                                               | 以 `\udXXX` 转义写入；若需签名则签名失败、按未签名写入并记警告                                                                                                                                                                                                                                              | JS 字符串语义                                                                      |
| RSA-PSS 限定的 PKCS#8 私钥                      | cryptography 按普通 RSA 处理                                                                                     | 同样按普通 RSA 处理                                                                                                                                                                                                                                                                                         | 对齐 Python                                                                        |
| 审计签名不支持 EC 私钥                          | `CertificateAuditSigner` 拒绝 EC 私钥（issue #10）                                                               | 以相同的 `TypeError` 文本拒绝                                                                                                                                                                                                                                                                               | 对齐 Python；两边都没有 ES256 签名器                                               |
| OIDC 发现文档 / JWKS 获取失败                   | 不缓存失败，排队的请求逐个重试；过期的缓存直接丢弃                                                               | 失败结果缓存 5 秒；身份提供方故障期间最多继续使用过期文档 10 × TTL（记警告）；`cache: { maxStaleSeconds: 0, failureCacheSeconds: 0, jwksRefreshCooldownSeconds: 0 }` 可恢复 Python 行为                                                                                                                     | 身份提供方卡住时避免请求串行超时                                                   |
| 未知 `kid` 触发的 JWKS 刷新                     | 每次都强制重新获取                                                                                               | 合并并发刷新，强制刷新有 30 秒冷却（与 jose 一致）；新轮换的密钥最多 30 秒后生效                                                                                                                                                                                                                            | 防止伪造 `kid` 驱动大量请求打到身份提供方                                          |
| OIDC HTTP 超时                                  | httpx 的 `timeout` 按阶段计                                                                                      | 整个请求（含响应体）一个总时限，取整到毫秒并限制在 1 ms ～ 2147483647 ms                                                                                                                                                                                                                                    | Node 定时器限制                                                                    |
| `requireRoles` / `requireScopes` 传入单个字符串 | 按字符迭代（`"ADMIN"` 变成 A、D、M、I、N）                                                                       | 类型上禁止，运行时抛 `TypeError`                                                                                                                                                                                                                                                                            | 避免误用                                                                           |
| OIDC 设备授权客户端                             | 同步 HTTP                                                                                                        | 方法返回 Promise；`close()` 为空操作                                                                                                                                                                                                                                                                        | Node 没有同步 HTTP                                                                 |
| `OidcClientError`                               | `str(exc)` 拼接各字段                                                                                            | `message` 等于 Python 的 `str(exc)`，原始消息在 `rawMessage`，属性为 camelCase（`errorDescription`、`statusCode`），缺省为 null                                                                                                                                                                             | 便于两边日志一致                                                                   |
| 令牌解析边界                                    | PyJWT 宽松 base64 接受 payload 段内含 `.` 的 4 段令牌；RSA 密钥 < 2048 位只警告；JWK 里的私钥参数也参与校验      | jose 拒绝 4 段令牌与 < 2048 位 RSA；导入前去掉 `d` 等私钥参数，只用公钥                                                                                                                                                                                                                                     | jose 的安全默认值                                                                  |
| 声明里的 `__proto__`                            | 作为普通声明保留                                                                                                 | 从 `raw_claims` 中去掉，不会污染原型                                                                                                                                                                                                                                                                        | 防止原型污染                                                                       |
| Partner 执行谁的命令                            | 接受任意群成员发出的任务命令与 LEAVE / DISBAND / MUTE 等管理命令                                                 | 启用身份绑定时只执行群组 Leader（`senderId` 等于 Leader AIC）发出的命令，其余丢弃                                                                                                                                                                                                                           | AIP §4.4、§7.2.2：只有 Leader 下发任务与要求退出                                   |
| Leader 群组消息路由                             | 按消息里自报的 `sessionId` 找会话                                                                                | 按接收该消息的会话处理，并要求 `groupId` 与该会话一致                                                                                                                                                                                                                                                       | 防止其他群的成员向本会话注入消息                                                   |
| 邀请超时 / 出错时的顺序                         | 先做 ACL 清理再结算邀请                                                                                          | 先结算邀请、清除待处理记录，再做 ACL 清理                                                                                                                                                                                                                                                                   | 避免迟到的“已加入”结果与清理竞争                                                   |
| 并发邀请同一 Partner                            | 检查与登记之间有 await，后一个调用会覆盖前一个，导致前一个永久挂起                                               | 在第一个 await 之前同步占位，ACL 失败时释放                                                                                                                                                                                                                                                                 | 修复 Python 侧问题                                                                 |
| 重复会话 id / 已加入时再次加入                  | 静默替换，旧资源泄漏                                                                                             | `createGroupSession` 抛错；已加入时 `joinGroup` 返回 `-32020 INVITATION_REJECTED`                                                                                                                                                                                                                           | 避免资源泄漏                                                                       |
| 收件箱与清理                                    | 退出群组会关闭收件箱所在的连接；半初始化的收件箱会被保留                                                         | 退出群组时保留收件箱连接；收件箱只在完全建立后才记录，失败时关闭通道以便下次重试；清理时关闭所有 SDK 未关闭的通道（包括正在重连的）                                                                                                                                                                         | 保证退出后仍能接收新邀请                                                           |
| 回滚与清理中的错误                              | 只捕获 `GroupAclError`，其他错误会覆盖原始错误                                                                   | 捕获全部错误并记日志，始终抛出原始错误                                                                                                                                                                                                                                                                      | 便于定位真正的失败原因                                                             |
| 日志中的 URL                                    | 原样记录                                                                                                         | 去掉其中的用户名与密码                                                                                                                                                                                                                                                                                      | 不在日志中暴露凭据                                                                 |
| AMQP URL 的 `?timeout=`                         | aiormq 解析但不使用                                                                                              | 作为连接超时（支持小数秒）                                                                                                                                                                                                                                                                                  | 让参数实际生效                                                                     |

## 7. 其他约定

- Python 枚举成员名原样保留（`TaskState.Accepted`、`GroupMgmtCommandType.GET_STATUS`），值与线上字符串一致。
- Python 方法返回的普通 dict（如 `GroupLeader.getGroupRuntime()`、群组模型的 `toDict()`）保留 snake_case 键，与 Python 返回值一致；acs / adp 模型的 `toDict()` 按别名输出 camelCase，与 Python `model_dump(by_alias=True)` 一致。
- Python 风格的字符串处理（`str.strip` 空白集合、`repr`、`json.dumps` 的分隔符等）集中在 `src/internal/pyCompat.ts`，供需要逐字节对齐的地方使用。
